# Журнал правок серии SH после серий CGO и CGR1

Ревизия промтов `SH0`–`SH9` на актуальность. Основание: серия **CGO** свела конфигурацию
`ClayGrid` в `ClayGridOptions` и зафиксировала конвенцию настроек в `AGENTS.md`;
серия **CGR1** переименовала `ClayGridDynamicOptions` → `ClayGridDynamicSettings`.
Файл — для истории; агенту читать не обязательно, ему достаточно исправленных промтов.

## 1. Блокирующая правка — не связана с CGO

**`SH7`, таблица элемента списка, строка «Удалить».** Было: «`DELETE` родительской записи;
параметры уходят каскадом (`SH2`)». Это противоречило `SH0` (ловушка 6), `SH2` п. 3 и `SH3`
операции 6, где каскада **нет намеренно**, а удаление делается двумя шагами.

Цена ошибки: агент либо получал падение на внешнем ключе, либо «исправлял» схему, добавив
`ON DELETE CASCADE`, — то есть создавал ровно ту дыру, которую `SH0` называет блокером: один
ошибочный `DELETE ... WHERE КодНастройкиОбщей = 0` сносит личные настройки всех пользователей
по всем гридам.

Стало: ссылка на операцию 6 из `SH3`, два шага атомарно, явный запрет каскада.

## 3. Ставшая невыполнимой сигнатура

**`SH4`.** Промт говорил «собрать все существующие **константы**-префиксы» и предлагал
`internal static IReadOnlyCollection<string> GetGridParamNames(int кодЗапроса)`.

Префиксы — не константы, а свойства `ClayGridDynamicSettings`, то есть значения из
`appsettings.json`. Статический метод без аргумента их не видит: он либо полез бы за
`IOptions<>` внутрь статики, либо продублировал бы значения константами — и тогда настройка
в конфигурации расходится с реестром, а проявится это как «несоответствие параметров» при
открытии по чужой ссылке.

Стало: `GetGridParamNames(ClayGridDynamicSettings settings, int кодЗапроса)`, настройки
подаются явно (метод остаётся чистой функцией и тестируется без DI); текст исключения при
превышении 20 символов обязан называть свойство-префикс; в `verify` добавлен тест с
искусственно длинным префиксом.

## 4. Редакторская правка

**`SH0`, ловушки.** Порядок был `1,2,3,4,5,6,8,9,10,11,12,7` — седьмая стояла после
двенадцатой. Абзац перемещён на своё место; перенумерация не потребовалась, ссылки вида
«ловушка 6» в других файлах не затронуты.

**`SH0`, индекс этапов.** Ячейка `SH2` говорила «…триггер, каскад», хотя `SH2` п. 3 —
«внешний ключ **без** каскада». Формулировка исправлена, чтобы индекс не противоречил этапу.

## 5. Открытый вопрос — решение за заказчиком

**Имя query-параметра `sharedId`.** `GridIdQueryParam` (`"id"`) и `ClientIdQueryParam`
(`"CLID"`) конфигурируемы в `ClayGridDynamicSettings`, а `sharedId` в `SH6`/`SH8` задан в коде.
Единообразнее было бы третье свойство `SharedIdQueryParam` со значением по умолчанию
`sharedId`.

Внесено в `SH0` как решение 8 с пометкой «подтвердите» и с **явным значением по умолчанию:
пока не подтверждено — константа**, чтобы этапы не разошлись. Если подтверждается — правка
на одну строку в `SH3` (третье свойство), `SH6` (сборка URL) и `SH8` (разбор).

## 6. Найдено попутно, вне серии SH

**`src/Clayzor.Lib.Web.Controls/AGENTS.md`, раздел «Настройки компонентов (Options)», пункт 7**
всё ещё пишет `Clay*DynamicOptions`, хотя правило именования тремя строками ниже уже говорит
`ClayGridDynamicSettings`. Строку пропустил шаг CGR1: она находится внутри раздела, добавленного
шагом CGO C2. Правка — одно слово; в промтах SH не отражена, поскольку `SH0` запрещает
трогать `AGENTS.md`.

## 7. Проверено и изменений не потребовало

- **`SH2`** — чистый SQL стенда: таблица, служебная запись `0`, уникальный ключ, триггер,
  внешний ключ без каскада, табличная функция. К изменениям в C# не привязан.
- **`SH6`** — сборка URL и буфер обмена: `NavigationManager`, `QueryHelpers`, JS-хелпер.
  Ничего из этого CGO не касался.
- **`SH8`** — разбор `sharedId`, строгая проверка имён, choke point запрета сохранения,
  признак режима на экране. Единственная связь с CGO — чтение заголовка грида, которое и так
  идёт через действующие настройки компонента.
- Матрица доступа к параметрам (`SH0` + `SH3` п. 1a), решения 1–7 в `SH0`, порядок этапов,
  разделы «Чего НЕ делать» и «Вне рамок» — актуальны как есть.
