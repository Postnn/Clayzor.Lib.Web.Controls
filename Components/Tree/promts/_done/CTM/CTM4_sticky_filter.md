# CTM4 — Липкая панель фильтра: раздельные контейнеры, скролл только у дерева

## Цель

Сейчас панель фильтра и список узлов лежат в одном контейнере `.clay-tree` и прокручиваются
вместе. Требование: если у дерева появляется вертикальный скролл, он начинается там, где начинается
само дерево, а панель фильтра остаётся на месте (не прокручивается).

Решение: разнести фильтр и дерево по разным контейнерам внутри корня. Скролл вешаем на контейнер
дерева, панель фильтра — вне области скролла.

## Шаг 1 — файл `Clayzor.Lib.Web.Controls/Components/Tree/ClayTreeView.razor`

Найти корневой блок:

```razor
<div class="clay-tree @Options.Class" style="@Options.Style">
    @* ── Панель фильтра ── *@
    @if (BuildFilterColumns().Count > 0)
    {
        <div class="clay-tree-toolbar"> ... </div>
    }

    @* ── Тело дерева (узлы) ── *@
    ...узлы, ошибки, оверлей...
</div>
```

Переструктурировать так, чтобы панель фильтра была ВНЕ прокручиваемого контейнера, а узлы —
ВНУТРИ него:

```razor
<div class="clay-tree @Options.Class" style="@Options.Style">

    @* ── Панель фильтра: НЕ прокручивается вместе с деревом ── *@
    @if (BuildFilterColumns().Count > 0)
    {
        <div class="clay-tree-toolbar">
            @* ...существующее содержимое тулбара без изменений... *@
        </div>
    }

    @* ── Прокручиваемое тело: только узлы ── *@
    <div class="clay-tree-scroll">
        @* сюда переносится ВЕСЬ блок, который сейчас рендерит корни/узлы/ошибку/оверлей,
           за исключением панели фильтра выше *@
        @* ...существующая разметка узлов, _error, busy-overlay... *@
    </div>

</div>
```

Важно: перенести внутрь `.clay-tree-scroll` именно рендер узлов (цикл по корневым `ClayTreeNodeView`)
и связанные с телом элементы (индикатор ошибки, оверлей `.clay-busy`, если он относится к телу).
Панель фильтра (`.clay-tree-toolbar`) остаётся снаружи. Ничего в самом содержимом тулбара и узлов
не менять — только вложенность.

## Шаг 2 — файл со стилями дерева (`clay-tree.css` или актуальный файл стилей компонента)

Найти файл стилей (искать по классу `.clay-tree` в `Clayzor.Lib.Web.Controls/wwwroot/`).
Добавить/скорректировать правила:

```css
/* Корень — колонка: фиксированная панель сверху + прокручиваемое тело снизу */
.clay-tree {
    display: flex;
    flex-direction: column;
    /* если у дерева задаётся ограниченная высота — она приходит через Options.Style
       (например height:600px); контейнер дерева использует оставшееся место */
    min-height: 0;
}

/* Панель фильтра не сжимается и не участвует в прокрутке */
.clay-tree-toolbar {
    flex: 0 0 auto;
    position: sticky;   /* подстраховка, если корень сам является скролл-контейнером */
    top: 0;
    z-index: 2;
    background: var(--mud-palette-surface, #fff);
}

/* Прокрутка только здесь */
.clay-tree-scroll {
    flex: 1 1 auto;
    min-height: 0;      /* критично для flex: разрешает контейнеру уменьшаться и скроллиться */
    overflow-y: auto;
}
```

Замечание: чтобы у дерева вообще был скролл, странице нужно задать ограниченную высоту корня —
через `Options.Style` (например `Style = "height:600px"`) или внешний CSS. Без ограничения высоты
контейнер растёт по содержимому и скролла не будет (это нормально). Правила выше корректно работают
в обоих случаях.

## Критерии приёмки

- При `Options.Style = "height:400px"` и большом дереве: панель фильтра остаётся на месте,
  прокручиваются только узлы; скролл начинается сразу под панелью фильтра.
- Без ограничения высоты — поведение как раньше (нет внутреннего скролла), фильтр над деревом.
- Панель фильтра визуально не наезжает на первый узел; фон панели непрозрачный (узлы не
  просвечивают под ней при прокрутке).
