# ClaySelect — руководство пользователя

`ClaySelect` используется для выбора одной сущности из локального списка или серверного
источника: сотрудника, типа оборудования, модели, ресурса и других объектов.

## Обычный поиск

1. Нажмите на поле и введите текст целиком или частично.
2. Запустите поиск одним из способов:
   - нажмите **Enter**;
   - перейдите в другое поле;
   - нажмите кнопку **«…»**.
3. Выберите строку в открывшемся списке.

Поиск не запускается на каждую нажатую клавишу. Это позволяет ввести запрос без лишних
обращений к серверу. Если совпадение одно и для поля включён автовыбор, оно может быть
выбрано автоматически. При нескольких совпадениях нужно явно выбрать строку.

Повторный Enter на неизменённом выбранном значении не открывает список и не повторяет запрос.

## Работа с клавиатурой

- **↓ / ↑** — переход между результатами.
- **Enter** — выбор активной строки или запуск поиска.
- **Escape** — отмена редактирования текста и восстановление прежнего выбора.
- **Tab** — переход к следующему полю.

Активная строка подсвечена. При движении мыши подсветка следует за указателем; при навигации
с клавиатуры используется активный индекс результата.

## Очистка и восстановление

Если очистка разрешена настройками формы, удалите текст поля. Значение идентификатора также
очищается.

Если текст редактировался, но новый элемент не выбран, Escape позволяет отменить редактирование
и восстановить сохранённый компонентом выбор.

В отключённом или доступном только для чтения поле подсказка для ввода не отображается; уже выбранное значение остаётся видимым.

## Дополнительные действия

В зависимости от настроек конкретной формы доступны:

- **Расширенный поиск** — отдельное окно с расширенными условиями. После выбора объекта его
  идентификатор возвращается в исходное поле. Закрытие окна без выбора ничего не меняет.
- **Создать элемент** — отдельная форма создания. Созданный объект выбирается автоматически,
  если форма вернула его идентификатор.
- **Просмотр** — после выбора объекта кнопка «…» может заменяться значком глаза. Он открывает
  карточку выбранного объекта, не изменяя выбор.

Одновременно открыт только один список `ClaySelect`. При прокрутке или изменении размера окна
его положение пересчитывается относительно видимой области: если снизу недостаточно места,
список открывается вверх. Список ограничен границами окна и не увеличивает прокрутку формы.

## Обязательные поля и ошибки

Обязательное поле нельзя сохранить пустым: сообщение появляется непосредственно под ним.
Высота сообщения не сдвигает открытый список.

Если сервер вернул ошибку, подробности отображаются общим баннером приложения. Уточните запрос
или повторите поиск после устранения причины.

## Особенности серверных списков

Серверный источник возвращает ограниченное число строк. Сообщение «Есть ещё результаты»
означает, что нужно уточнить запрос. При редактировании существующей записи выбранный объект
восстанавливается по его идентификатору, даже если его нет в первой странице результатов.

Для программного интерфейса и интеграции внешнего поиска см. техническую документацию
`Components/Select/ClaySelect.razor.cs` и `Services/ClaySelectAdvancedSearchService.cs`.
